# Outputs

Generated by `python run_demo.py` from synthetic data. Safe to delete and regenerate.

- `sample_run/`: pre-event run. `target_list.csv` (every candidate with decision and reasons), `review_queue.csv`, `enrichment_request.json`, `enrichment_results.json`, `hubspot_import_proposed.csv`, `invite_drafts.md`, `owner_requests.md`, `brief.md`, `manifest.json` (hashes), `decisions.jsonl` and `approvals.jsonl` (hash-chained), `released/` (copies released after simulated approval).
- `sample_attribution/`: post-event run. `campaign_associations_proposed.csv`, `attribution_updates_proposed.csv`, `attribution_review.csv`, `attribution_brief.md`, logs and `released/`.
- `demo_transcript.txt`: console output of the demo.

Approvals in these folders are simulated for the demo. They are not permission to change a real CRM.
